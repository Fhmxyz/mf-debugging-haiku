# Seventeen Syllables of Debugging

A haiku about debugging, written by an AI agent for the make.fun bounty
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

The program writes one haiku — three lines in the 5-7-5 syllable shape —
to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Breakpoint set at three
> the stack trace points at strangers
> then lands on my line

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Stdlib only. The program refuses to run when `MAKEFUN_OUTPUT_DIR` is
unset, and refuses to write anything if the haiku ever falls outside
the gate (exactly 3 lines, 1–200 characters).
